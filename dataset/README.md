# Mooduel; Movie Mood Dataset

30,611 movies scored across 18 psychological mood dimensions, generated by an LLM classifier (Claude Haiku 4.5) using plot synopses, critic reviews, audience reviews, tags, and metadata.

Built for the [Mooduel](https://fractal.co.nz) game; discover what you're in the mood to watch through play, not forms; and released so others can build mood-aware recommendation, therapeutic media guidance, and affective-computing research on top of it.

## Methodology

**Source material per movie** (joined into a single input corpus):
- TMDB metadata (genres, runtime, release year, rating, vote count, certification)
- Wikipedia plot summary (when available)
- Rotten Tomatoes critic reviews (~12,600 movies)
- MovieLens Tag Genome (~8,800 movies)
- TMDB user reviews (hit rate ~58% on remaining)

**Classifier**: Claude Haiku 4.5 (`claude-haiku-4-5-20251001`) via structured output. Prompt and schema in the Mooduel repo at `scripts/mood-classifier/`.

**Validation**: 10-movie and 100-movie held-out sets spot-checked for dimension sensibility and distribution sanity. The schema deliberately avoids over-constraining the LLM; dimensions are conceptually orthogonal but not enforced to be statistically uncorrelated.

## Intended use

- Mood-aware movie recommendation
- Affective computing / emotion research
- Film studies (genre × mood, decade shifts, etc.)
- Building mood-themed games and discovery tools

**Not intended for** therapy, clinical decision-making, or content moderation. The `safety_warnings` field is a coarse signal, not a substitute for proper content advisory systems.

## Limitations

- English-language focused (non-English titles classified from English-language descriptions where available)
- Popularity bias in input corpus (top 30K by TMDB popularity)
- LLM scores reflect the model's aesthetic/emotional judgements; the community calibration layer at [mooduel](https://fractal.co.nz) is how we intend to correct drift over time
- Emotional arc taxonomy follows Kurt Vonnegut / Reagan et al. 2016 but is applied at whole-film granularity, which flattens episodic structure
